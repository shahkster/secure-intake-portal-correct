STANDALONE SECURE INTAKE PORTAL

This version works without a CRM.

YOU NEED
1. Supabase account
2. Vercel account
3. Node.js LTS

FIRST
1. Create a Supabase project.
2. Run supabase/schema.sql in Supabase SQL Editor.
3. Copy your Supabase Project URL and sb_secret key.

LOCAL TEST
Mac: double-click start-mac.command
Windows: double-click start-windows.bat

ONLINE DEPLOYMENT
1. npm install
2. npx vercel login
3. npx vercel link
4. Add all .env.local values in Vercel Project Settings > Environment Variables
5. npx vercel --prod

Read README.md for the exact step-by-step instructions.
Use fake information until the site has received an independent security and compliance review.


UPDATING AN EXISTING INSTALLATION
---------------------------------
If this portal is already connected to Supabase, open Supabase SQL Editor and
run supabase/add-dob-option.sql once. This adds Date of Birth as a separate
request option without deleting existing requests.
