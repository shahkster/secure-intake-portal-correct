LEGACY COMFORT DIALER (Google Voice helper)

What it does: when you dial a lead from the CRM with "Google Voice" picked,
Voice opens with the number filled in. This helper presses the Call button for you,
so auto-dial really dials. It only runs on voice.google.com, only when the CRM sent
the number, and only clicks Call when that exact number is on the screen.
Google Voice only works in one tab at a time, so each new dial closes the Voice tab
the CRM opened for the last call (it never closes a Voice tab you opened yourself).

Install (Chrome, one time):
1. Unzip this file. You get a folder called "legacy-comfort-dialer".
2. In Chrome, go to chrome://extensions
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and pick the "legacy-comfort-dialer" folder.
5. Keep the folder where it is (don't delete it), or Chrome turns the helper off.
